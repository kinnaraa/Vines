**About:**

Vines is a procedural vine-growth system that I developed to simulate surface-driven plant growth across 3D environments. I began the project by researching the real-world growth behavior of English ivy and identifying the underlying patterns that could be translated into procedural rules. I then used Houdini to prototype the system and test procedural mesh-generation workflows before rebuilding it in Unity with C# for real-time execution.

The final system generates vines dynamically across surfaces, using custom growth logic and mesh generation to create an adaptable and tunable procedural tool. A major focus of the project was balancing believable organic behavior with performance, especially as the system scaled to larger use cases.


**Challenges:**

- Translating real-world plant growth behavior into procedural rules
- Building a system that could grow across varied 3D surfaces without clipping
- Optimizing the system to remain scalable as vine density and usage increased
